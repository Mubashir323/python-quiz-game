# 📝 Python Quiz Game

A beginner-friendly Python quiz game that tests basic Python programming knowledge.

## 📌 About

I created this project to practice Python programming, user input, conditions, variables, and score tracking.

## ✨ Features

- Asks the player's name
- Provides 3 Python questions
- Accepts multiple-choice answers
- Shows correct or wrong feedback
- Tracks the player's score
- Displays the final score

## 🛠️ Technology

- Python 3

## 📚 What I Learned

- `input()`
- Variables
- `if` and `else`
- `score += 1`
- String methods
- User input
- Basic problem-solving

## ▶️ How to Run

Make sure Python is installed.

Open Command Prompt in the project folder and run:

```bash
py quiz_game.py
